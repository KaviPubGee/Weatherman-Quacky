# Weatherman-Quacky

A cute and cozy weather website that changes the entire vibe based on the current weather 

Sunny skies? The duck chills in the sun 
Rain outside? Tiny raincoat duck appears  
Cloudy day? Sleepy cloudy duck vibes 

The app fetches real-time weather data and dynamically updates:
-  Animated video backgrounds
-  Weather-themed duck characters
-  Temperature and weather information
-  City-based weather search

---

## Features

-  Search weather by city
-  Dynamic weather conditions
-  Animated backgrounds based on weather
-  Cute duck reactions for each weather type
-  Clean and responsive UI

---

##  Weather Themes

| Weather | Background | Duck Mood |
|---|---|---|
| ☀️ Sunny | Bright sunny video | Sunbathing duck |
| 🌧️ Rainy | Rain animation/video | Duck with raincoat |
| ☁️ Cloudy | Soft cloudy background | Sleepy duck |

## How To Run

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/duck-weather.git
```

### 2. Open the project folder

```bash
cd duck-weather
```

### 3. Run the app

Open `index.html` in your browser.
